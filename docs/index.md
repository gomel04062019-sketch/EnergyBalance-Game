\## 💻 Техническая реализация

Проект разработан на игровом движке \*\*GameMaker (LTS 2026)\*\* с использованием языка \*\*GML\*\*. 



\*\*Архитектура проекта:\*\*

\*   \*\*Паттерн:\*\* Централизованный контроллер (`obj\_controller`), который управляет экономикой, погодой и квестами.

\*   \*\*UI:\*\* Отрисовка интерфейса полностью вынесена в событие `Draw GUI` с использованием ассетов `Sprout Lands`.

\*   \*\*Генерация карты:\*\* Изометрическая сетка генерируется процедурно (вода, песок, трава) с помощью циклов и привязки к координатам.

\## 🎮 Управление в игре



| Действие | Клавиша / Кнопка мыши |

| :--- | :--- |

| \*\*Выбор здания\*\* | `1` (Дом), `2` (ТЭЦ), `3` (Солнце), `4` (Ветер) |

| \*\*Постройка\*\* | Левая кнопка мыши (ЛКМ) |

| \*\*Отмена постройки / Снос\*\* | Правая кнопка мыши (ПКМ) |

| \*\*Движение камеры\*\* | `W`, `A`, `S`, `D` или Стрелки |

| \*\*Дерево технологий\*\* | `T` |

| \*\*Меню паузы\*\* | `ESC` |

| \*\*Полноэкранный режим\*\* | `F11` |
