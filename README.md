\# Энергобаланс города (Energy Balance)



Образовательная компьютерная игра в жанре экономической стратегии, разработанная для республиканского конкурса «Энергомарафон-2026».



\## 📌 Описание проекта

Игрок выступает в роли мэра города. Его главная задача — обеспечивать город электроэнергией, не выходя за бюджет, при этом сохраняя высокий уровень экологии. В игре реализована система квестов, дерево технологий (энергоэффективность), а также динамическая смена погоды и времени суток.



\## 🛠 Технический стек (Зафиксирован)

\*   \*\*Игровой движок:\*\* GameMaker (LTS версия)

\*   \*\*Версия IDE:\*\* v2026.0.0.16

\*   \*\*Версия Runtime:\*\* v2026.0.0.23

\*   \*\*Язык программирования:\*\* GML (GameMaker Language)

\*   \*\*ОС для разработки:\*\* Windows (x64)



\### Почему выбран этот стек?

1\.  \*\*Скорость разработки:\*\* GML позволяет быстро реализовывать игровую логику (экономика, квесты, строительство).

2\.  \*\*Работа с 2D-графикой:\*\* GameMaker идеально подходит для изометрических игр и пиксель-арта.

3\.  \*\*Стабильность:\*\* LTS (Long Term Support) версия гарантирует отсутствие критических багов во время сборки проекта.



\## 🎮 Основные механики

\*   \*\*Строительство:\*\* Изометрическая сетка, запрет наложения зданий, ограничение постройки (только на траве).

\*   \*\*Энергосистема:\*\* Баланс между выработкой (ТЭЦ, Солнце, Ветер) и потреблением (дома).

\*   \*\*Экология:\*\* Загрязнение от ТЭЦ снижает общий эко-рейтинг, что ведет к штрафам.

\*   \*\*Дерево технологий (Клавиша T):\*\* Позволяет купить «Утепление домов» (снижает потребление) и «Фильтры для ТЭЦ» (снижает загрязнение).

\*   \*\*Квестовая система:\*\* 5 последовательных заданий, ведущих к победе.



\## 🚀 Как запустить

1\. Скачайте и установите \*\*GameMaker\*\* (версия LTS или новее).

2\. Откройте файл проекта `.yyp`.

3\. Нажмите \*\*F5\*\* (или зеленую кнопку Play) для сборки и запуска игры.
